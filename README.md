# Лабораторная 2

### Общая структура лабораторных

Все задания описаны в корневом файле `README.md`.

Ваши решения вы публикуете в этом же репозитории.

Для каждого задания вы создаете папку `task-XX`, где `XX` - номер задания (возможно, начинающееся с 0).
В эту папку вы складываете все файлы, относящиеся к решению. Как правило, это будет bash скрипт с названием `solution.sh`.
Решения проверяются автоматически, поэтому важно соблюдать структуру проекта.

Ваши решения будут запущены в Docker-образе, подготовленном для этой лабораторной.
Если вы хотите прогнать свой скрипт у себя локально в том же окружении, изучите файл с конфигурацией GitHub Actions
для проверки вашей лабораторной, и подтяните соответствующий образ.

**Изменения в папке `.github` запрещены.**

Тесты публичные, их можно посмотреть в Docker-образе. 
Работы дополнительно проверяются вручную, поэтому просто захардкодить ответы нельзя.

### Сдача лабораторной

При создании репозитория у вас автоматически создался Pull Request из ветки main в ветку, 
в которой хранится первоначальное состояние вашего репозитория.

При каждом коммите в main у вас автоматически будут прогоняться тесты, после чего вы получите отчет
о результатах в виде комментария в PR.

После наступления дедлайна преподаватель вручную смотрит все PR студентов и выставляет в ведомость баллы за задания с пройденными тестами.

## Задание 1

**Стоимость: 1.5 балла.**

Создайте директорию `task1`. 

В `task1` создайте директорию `biggest`, скопируйте в неё 10 самых больших файлов из директории `/workspace/data`, 
а также создайте директорию `smallest` и скопируйте в неё 10 самых маленьких файлов из `/workspace/data`.

Решением этой задачи будет несколько команд. Каждая новая команда должна начинаться с новой строки в файле `solution.sh`.

## Задание 2

**Стоимость: 1.5 балла.**

Выведите суммарный размер (в байтах) файлов, содержащих слово bash, из директории `/workspace/data`.

## Задание 3

**Стоимость: 1.5 балла.**

Запишите в файл `bash_lines.txt` строки, содержащие слово bash, из файлов в директории `/etc` (рекурсивно).

## Задание 4

**Стоимость: 1 балл за каждый пункт, всего 3.**

Команды `sort` и `uniq` позволяют реализовать некое подобие операций над множествами, где элементы — это строки файлов. 
Придумайте, как реализовать следующее (не стесняйтесь заглядывать в man страницы этих команд):

- Создайте файл `union`, который содержит все уникальные строки из файлов `file1` и `file2`
- Создайте файл `intersection`, в котором будут уникальные строки, содержащиеся одновременно в обоих файлах (`file1` и `file2`)
- Создайте файл `difference`, содержащий уникальные строки, которые содержатся в `file1`, но отсутствуют в `file2`

## Задание 5

**Стоимость: 1.5 балла.**

Создайте директорию `task5`. В `task5` создайте директорию с именем каждого пользователя в системе.

Имена пользователей в системе можно получить из файла `/etc/passwd`. 
Этот файл содержит список пользователей и параметры. Значения разделены двоеточием. Первый столбец — имя пользователя.

## Задание 6

**Стоимость: 1.5 балла.**

Найдите 100 самых больших файлов в директории `/usr/bin`, затем выведите тот из них, который был последний раз модифицирован раньше остальных.
